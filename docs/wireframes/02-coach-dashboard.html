Desktop. On a phone the table collapses to stacked cards, each showing name, age, days since last log, and flags only.

Annotations

  1. Two verbs, not a menu. A coach opens this app to do one of two things: record something that just happened, or add someone new. Those are the only two buttons at this level. Everything else is navigation.
  2. Overdue is the metric that earns its place. Squad size never changes and tells the coach nothing. Days since last measurement is the number that decides whether the growth curves are worth anything, so it is promoted to the top and drives the default sort.
  3. The attention strip is a queue, not a notification. Each chip filters the table below rather than opening somewhere else. A coach with nothing outstanding sees this strip empty, which is a real and good state, not a bug.
  4. The trend cell is a sparkline of the last six measurements. It exists so a coach can spot a flat line without opening a profile. It is not interactive and it carries no axis. If it cannot be made legible at this size it should be cut rather than shrunk further.

Data and API

  • Player joined through PlayerOrganization, filtered to the coach's own organization, with the affiliation still open. Scoping happens in the API, never in the frontend.
  • Days since last log comes from the most recent Measurement per player. That is a per player aggregate, so the endpoint should return it rather than the frontend fetching measurements for 24 players.
  • The sparkline needs the last six height_cm values per player. Worth deciding whether that ships with the list or loads after, because it is the one thing on this page that could make it slow.
  • Flags come from the ML layer, read only here.
  • Consent state comes from Consent, filtered to purposes that matter for a minor.

Open questions

  • A coach at a club with several age groups needs a squad switcher. Right now the org is a single chip in the nav. Does PlayerOrganization carry enough to group by age band, or does the coach just filter by age?
  • What counts as overdue? Ninety days is drawn here because it is plausible, not because anyone decided it. It probably differs between a youth academy and a professional club.
  • Should a coach see ML flags at all, or only the federation? Showing a coach that their own player is flagged for a suspicious jump is either useful transparency or an invitation to game the detector. This is a real tension and the security and ML tracks should settle it.
