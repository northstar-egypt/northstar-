NorthStar screen wireframes

Eight screens, drawn before any of them is built, so the team can argue about what belongs on a page while it is still cheap to change. These are greyscale on purpose. Layout, hierarchy, and content are under review here. Colour, typography, and spacing are not decided yet.

How to read these

  • Solid boxes are real interface elements: buttons, inputs, cards, rows.
  • Dashed hatched boxes are generated content: a chart, a photo, a forecast, a model output. The shape is a claim about the space it needs, not about how it looks.
  • Numbered markers point to the annotation list underneath each wireframe. That is where the reasoning lives.
  • Every screen page ends with the data it needs, the access rules that apply, and the open questions the app track cannot answer alone.

Consent gated means

A scout viewing a minor sees the profile only if a valid scouting_visibility consent record exists for that player. Otherwise the profile is withheld. What "withheld" looks like is an open question: hide the player from search results entirely, or show a locked card that says consent is required. The second is more honest and lets a coach chase the consent. The first leaks less. This needs a decision from the security track.

Principles these follow

  • Mobile first where it matters. Coach logging happens pitchside on a phone, in the sun, possibly with one hand. That screen is drawn at phone width first and desktop second. The analysis screens are the other way round.
  • Uncertainty is shown, never hidden. Any forecast on screen carries its uncertainty band. A number the model is unsure about must not look like a number it is sure about.
  • A flag is a claim, not a verdict. Everywhere the system flags something, the interface says why, and offers a human the ability to disagree. The audit log records both.
  • The database is the source of truth for the assistant. Where an AI summary appears, it phrases what the data already says. It never introduces a number that is not on the screen already.
