# Dependencies for ml/.
#
# Kept separate from apps/api/requirements.txt on purpose: the API image installs
# only its own file, so nothing here reaches the container that serves requests.
#
# The detectors and the scoring harness are deliberately standard-library only.
# The population is a few hundred players and a few thousand measurements, which
# is small enough that pandas would cost more in review effort than it saves in
# runtime, and it means `python -m ml.run_eval` works in any environment that can
# already run the generator. Nothing below is needed to produce the numbers.
#
# One exception, deliberate: the fraud detector's arithmetic rule calls the sport
# modules' validator in apps/api/app/sports.py (see ml/sport_modules.py), so that
# ingest and the detector share one definition of an impossible record. That
# validator is itself standard library, but importing the API package needs the
# generator's environment below, which the harness needs anyway.
#
# Running the harness needs the generator's environment, because the evaluation
# reads the dataset it produces and the seed sweep builds datasets in process:
#
#     pip install -r data/pipelines/requirements.txt
#     pip install -r ml/requirements.txt

# The challenger models (ml/challengers), which put the methods the thesis names through the
# same evaluation as the v1 models: an isolation forest for age misrepresentation, and XGBoost
# for the height forecast. Only the challengers import these; the v1 detectors and forecasters
# stay standard library only, and the API never imports ml/challengers. Without them the
# harness still runs and says the challengers were skipped.
# scikit-learn also cross-checks our precision/recall/F1 in ml/tests/test_metrics.py.
scikit-learn==1.5.*
xgboost==3.0.*

pytest==8.3.*

# The height forecasters (ml/forecasting) are standard-library only as well. v1 is a
# learned population growth curve, which needs medians and interpolation, not a
# gradient boosting library. If a trained model replaces it, add the dependency
# then, and note why it is here.
